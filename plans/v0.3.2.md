# Plan v0.3.2 - Save/Load Custom Equations

**Fractal**: TBD - to be determined before release finalization

## Overview
Version 0.3.2 adds the ability to save, load, and share custom equation fractals as reusable files.

## Dependencies
- **v0.3.1** - Custom equation fractal implementation
- Colormap save/load system (patterns to follow)

## Feature: Equation Library

### User Experience

Users can:
1. Save current custom equation to a file
2. Load equations from files
3. Browse built-in equation library
4. Share equations with others

### File Format

**`.ffeq` (Forma Fractalis Equation)** - JSON format:

```json
{
  "version": "1.0",
  "name": "Celtic Mandelbrot",
  "description": "Creates Celtic cross patterns in the fractal",
  "author": "User Name",
  "equation": "abs(re(z^2)) + i*im(z^2) + c",
  "escape_radius": 2.0,
  "escape_mode": "magnitude",
  "initial_z": "0",
  "suggested_view": {
    "center_x": -0.5,
    "center_y": 0.0,
    "zoom": 1.0
  },
  "suggested_iterations": 256,
  "suggested_colormap": "Fire"
}
```

### Sharing

- [ ] Equations are plain JSON, shareable via any method
- [ ] Consider future: community equation repository?
- [ ] Include checksum/hash for integrity verification

### Migration Path

When custom equations are saved in project files (v0.3.3), they reference `.ffeq` files rather than embedding the equation. This enables:
- Updating an equation updates all projects using it
- Smaller project files
- Clear provenance

## Hi-Precision Implementation
This release adds hi-prec CPU support for **Multifractal Julia**.

Multifractal Julia has multiple c constants and stochastic selection. The hi-prec path should use the same random selection seed logic as the f64 path to maintain agreement.
