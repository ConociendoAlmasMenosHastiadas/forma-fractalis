## GPU Per-Fractal Phasing

### MarekDragon GPU Implementation
Per v0.2.0's gradual GPU rollout strategy, this release adds GPU support for **MarekDragon**.

**Implementation:**
- [x] Create `marek_dragon.wgsl` shader
- [x] MarekDragon iteration: `z_{n+1} = exp(j*phi)*z_n + z_n^2`
- [x] Handle phi parameter as uniform input
- [x] exp(j*phi) = cos(phi) + j*sin(phi) - compute in shader
- [x] Add MarekDragon to GPU-capable fractal list
- [x] Test: Verify rotation parameter (phi) produces identical results to CPU
- [x] Test edge cases: phi = 0, phi = pi, phi = pi/2

**Technical Notes:**
- The exponential rotation `exp(j*phi)` can be precomputed on CPU and passed as uniform
- Alternative: pass phi and compute cos/sin in shader (more flexible for animation)
- For animation purposes (future GIF work), computing in shader may be better

**Shader Pseudocode:**
```wgsl
fn iterate_marek_dragon(c: vec2<f32>, phi: f32, max_iter: u32) -> u32 {
    var z = vec2<f32>(0.0, 0.0);
    let rotation = vec2<f32>(cos(phi), sin(phi));
    
    for (var i = 0u; i < max_iter; i++) {
        let rotated = complex_mul(rotation, z);
        let z_squared = complex_mul(z, z);
        z = rotated + z_squared;
        
        if (dot(z, z) > 4.0) {
            return i;
        }
    }
    return max_iter;
}
```
