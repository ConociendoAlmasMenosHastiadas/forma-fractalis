## Hi-Precision Implementation
This release adds hi-prec CPU support for **Tetration**.

Tetration z(n+1) = c^z_n uses exponential and logarithm. BigFloat provides exp() and ln(). Handle convergence criterion (Tetration doesn't use escape radius -- uses |z| > threshold instead).
