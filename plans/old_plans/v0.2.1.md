## GPU Per-Fractal Phasing
Per v0.2.0's gradual GPU rollout strategy, this release adds GPU support for **Julia Set**.
- Julia Set is ideal: same iteration as Mandelbrot but with c as uniform parameter
- Shader: `julia_kernel.wgsl` (adapted from mandelbrot_kernel.wgsl, c comes from uniform instead of pixel coordinates)
- Animation synergy: GPU-accelerated Julia enables smooth parameter sweep animations

**Fractal of the release**
Sin Julia: z_{n+1} = c*sin(z_n).  c is a free parameter that should have the same kind of rectangular and polar inputs as the Julia set.  
z_0 = x+jy whith x y being the points obtained from position in the complex plane.

to simplify some of the math:
x_{n+1} = sin(x_n)*cosh(y_n)
y_{n+1} = cos(x_n)*sinh(y_n)
z_n = x_n + j*y_n

reference: https://paulbourke.net/fractals/sinjulia/
