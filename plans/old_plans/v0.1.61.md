# Forma Fractalis v0.1.61 - Colormap Library Extraction

**Fractal**: Exempt - not a feature release
**Status:** Complete
**Type:** Organizational Refactoring
**Released:** 2026-02-05

## Overview
Extract colormap functionality into a standalone crate `scala-chromatica` to enable reuse across other Rust projects. This creates a clean, framework-agnostic color gradient library while maintaining forma-fractalis functionality through the deprecation process.

## Goals
1. Create minimal, reusable scala-chromatica crate with core colormap functionality
2. Establish scala-chromatica as a separate GitHub repository and crates.io package
3. Update forma-fractalis to use scala-chromatica as a dependency
4. Maintain backwards compatibility during deprecation period
5. Keep GUI functionality (colorschemes_gui.rs) in forma-fractalis

//! scala-chromatica: A framework-agnostic color gradient library
//!
//! This library provides smooth color interpolation, gradient management,
//! and persistent storage for color schemes. Perfect for data visualization,
//! fractal rendering, scientific plots, and any application requiring
//! sophisticated color mapping.
//!
//! # Features
//! - Smooth RGB interpolation between color stops
//! - HSV color space support
//! - JSON serialization/deserialization
//! - Built-in color schemes (Fire, Ocean, Rainbow, etc.)
//! - Platform-specific config directory management
//! - Custom colormap save/load
//!
//! # Quick Start
//! ```rust
//! use scala_chromatica::{ColorMap, Color};
//!
//! // Load a built-in colormap
//! let fire = scala_chromatica::io::load_builtin_colormap("Fire").unwrap();
//!
//! // Get color at 50% position
//! let color = fire.get_color(0.5);
//! println!("RGB: ({}, {}, {})", color.r, color.g, color.b);
//!
//! // Create a custom gradient
//! let mut custom = ColorMap::new("MyGradient");
//! custom.add_stop(ColorStop::new(0.0, Color::new(255, 0, 0)));
//! custom.add_stop(ColorStop::new(1.0, Color::new(0, 0, 255)));
//!
//! // Save for later use
//! scala_chromatica::io::save_colormap(&custom).unwrap();
//! ```

pub mod color;
pub mod colormap;
pub mod error;
pub mod io;

// Re-export main types at crate root for convenience
pub use color::Color;
pub use colormap::{ColorMap, ColorStop};
pub use error::{ColorMapError, Result};

### Step 1.7: Create Examples
**File:** `scala-chromatica/examples/basic_usage.rs`

```rust
//! Basic usage example showing colormap loading and color sampling

use scala_chromatica::{ColorMap, Color, ColorStop};

fn main() {
    // Load built-in colormap
    println!("Loading Fire colormap...");
    let fire = scala_chromatica::io::load_builtin_colormap("Fire")
        .expect("Failed to load Fire colormap");
    
    // Sample colors at different positions
    println!("\nFire gradient samples:");
    for i in 0..=10 {
        let position = i as f64 / 10.0;
        let color = fire.get_color(position);
        println!("  {:.1}: RGB({}, {}, {})", position, color.r, color.g, color.b);
    }
    
    // Create custom gradient
    println!("\nCreating custom gradient...");
    let mut custom = ColorMap::new("RedBlue");
    custom.add_stop(ColorStop::new(0.0, Color::new(255, 0, 0)));
    custom.add_stop(ColorStop::new(0.5, Color::new(255, 255, 255)));
    custom.add_stop(ColorStop::new(1.0, Color::new(0, 0, 255)));
    
    println!("\nCustom gradient samples:");
    for i in 0..=10 {
        let position = i as f64 / 10.0;
        let color = custom.get_color(position);
        println!("  {:.1}: RGB({}, {}, {})", position, color.r, color.g, color.b);
    }
}
```

```rust
//! Integration tests for scala-chromatica

use scala_chromatica::{ColorMap, Color, ColorStop};

#[test]
fn test_load_builtin_colormaps() {
    let builtin = ["Default", "Fire", "Ocean", "Grayscale", "Rainbow"];
    
    for name in builtin {
        let colormap = scala_chromatica::io::load_builtin_colormap(name);
        assert!(colormap.is_ok(), "Failed to load {}", name);
    }
}

#[test]
fn test_color_interpolation() {
    let red = Color::new(255, 0, 0);
    let blue = Color::new(0, 0, 255);
    
    let mid = red.lerp(&blue, 0.5);
    assert_eq!(mid.r, 127);
    assert_eq!(mid.b, 127);
}

#[test]
fn test_colormap_gradient() {
    let mut map = ColorMap::new("Test");
    map.add_stop(ColorStop::new(0.0, Color::new(0, 0, 0)));
    map.add_stop(ColorStop::new(1.0, Color::new(255, 255, 255)));
    
    let start = map.get_color(0.0);
    assert_eq!(start.r, 0);
    
    let end = map.get_color(1.0);
    assert_eq!(end.r, 255);
    
    let mid = map.get_color(0.5);
    assert!(mid.r > 100 && mid.r < 200);
}
```

/// Application-specific color scheme enum

    Default,

    Rainbow,

        ColorScheme::Fire,
        ColorScheme::Ocean,
        ColorScheme::Grayscale,
        ColorScheme::Rainbow,

    pub fn as_str(&self) -> &'static str {
        match self {
            ColorScheme::Default => "Default",
            ColorScheme::Fire => "Fire",
            ColorScheme::Ocean => "Ocean",
            ColorScheme::Grayscale => "Grayscale",
            ColorScheme::Rainbow => "Rainbow",
        }
    }

    pub fn to_colormap(&self) -> ColorMap {
        scala_chromatica::io::load_builtin_colormap(self.as_str())
            .expect("Built-in colormap should always load")

## Notes & Decisions

### Why "scala-chromatica"?
- "Scala" = scale/gradient concept (not the programming language)
- "Chromatica" = relating to color
- Unique name, easy to remember, describes functionality

### Why No GUI in scala-chromatica?
- Different projects use different GUI frameworks (egui, iced, druid, web)
- GUI design is subjective and project-specific
- Keeps dependencies minimal (no egui or rfd required)
- forma-fractalis remains excellent reference implementation

### Deprecation Strategy
- One-version grace period (v0.1.61) with compiler warnings
- Complete removal in v0.1.7
- Bridge modules ensure no breakage during transition
- Clear migration guide in documentation

### Testing Strategy
- Unit tests in scala-chromatica for core functionality
- Integration tests in scala-chromatica for I/O
- forma-fractalis existing test suite catches regressions
- Manual GUI testing for colormap dropdown and editor
