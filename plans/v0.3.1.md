## Feature: Custom Equation Fractal

### User Experience

Users can enter a custom iteration formula using a mathematical expression language:

```
z = z^2 + c           // Standard Mandelbrot
z = z^3 + c           // Cubic Mandelbrot
z = sin(z) + c        // Sine fractal
z = z^2 + z + c       // Quadratic variant
z = exp(z*c)          // Exponential fractal
```

### Expression Language

#### Supported Operations
- **Arithmetic**: `+`, `-`, `*`, `/`, `^` (power)
- **Functions**: `sin`, `cos`, `tan`, `exp`, `ln`, `sqrt`, `abs`
- **Complex**: `re(z)`, `im(z)`, `conj(z)`, `arg(z)`
- **Constants**: `pi`, `e`, `i` (imaginary unit)

#### Variables
- `z` - Current iteration value (starts at 0 or configurable)
- `c` - Pixel coordinate in complex plane
- `n` - Current iteration number

### GPU Considerations

Custom equations present a GPU challenge: shaders are compiled ahead of time, but custom equations are dynamic.

**Options:**
1. **CPU-only for custom equations** - Simplest, defer GPU to a later release after the variable/project groundwork is stable
2. **Runtime shader compilation** - Generate WGSL from expression, compile at runtime
3. **Interpreter on GPU** - Stack-based expression evaluator in shader (complex, slow)

**Recommendation:** Start with CPU-only (option 1). GPU support can be added later if demand exists.
