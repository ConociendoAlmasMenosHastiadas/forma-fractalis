# Plan v0.3.3 - Project System

**Fractal**: TBD - to be determined before release finalization

## Overview
Version 0.3.3 introduces a project system, allowing users to organize related fractal explorations, define reusable variables, and manage complex workflows.

## Dependencies
- **v0.3.2** - Save/load equations (projects reference equations)
- **v0.3.0** - Job queue (projects can batch-queue renders)
- Colormap save/load (projects reference colormaps)

## Feature: Project System

### User Experience

**Before (current):** User works on one fractal at a time. Settings are ephemeral unless exported.

**After (with projects):** User creates a project containing multiple fractals, shared variables, and export configurations. Projects persist across sessions.

### Project Structure

```
my_project.ffproj (JSON)
├── metadata
│   ├── name: "Deep Zoom Collection"
│   ├── description: "..."
│   └── created/modified dates
├── variables
│   ├── zoom_target_x: -0.743643887
│   ├── zoom_target_y: 0.131825904
│   └── base_iterations: 256
├── fractals[]
│   ├── fractal_1
│   │   ├── name: "Overview"
│   │   ├── type: "Mandelbrot"
│   │   ├── view: { center: (0,0), zoom: 1 }
│   │   └── iterations: ${base_iterations}
│   └── fractal_2
│       ├── name: "Detail"
│       ├── type: "Mandelbrot"
│       ├── view: { center: (${zoom_target_x}, ${zoom_target_y}), zoom: 10000 }
│       └── iterations: ${base_iterations} * 4
├── export_presets[]
│   └── preset_1
│       ├── name: "4K Wallpapers"
│       ├── width: 3840, height: 2160
│       └── fractals: ["Overview", "Detail"]
└── queue_jobs[] (pending exports)
```

### Variable Expression Syntax

Simple expression language for variable values:
- References: `${var_name}`
- Arithmetic: `${base * 2}`, `${width / 16 * 9}`
- Functions: `${min(a, b)}`, `${max(a, b)}`

**Note:** This is simpler than the custom equation parser (v0.3.1). Consider reusing parser infrastructure if applicable.
